Questions

Is Perch free?

Yes. Perch is free and open source under the MIT license. There’s no account, subscription, ads or tracking.

Which Macs does it run on?

macOS 14 Sonoma or later, on Apple Silicon Macs. Intel Macs aren’t supported.

Is it on the Mac App Store?

No. Perch needs system access the App Store sandbox doesn’t allow. Get it from this site, the Terminal command or Homebrew.

Will it work with my mouse?

Yes, with any mouse your Mac sees. Click Scan buttons in the Mouse tab to detect every button, including the extra ones. Your trackpad settings aren’t touched.

Can each app behave differently?

Yes. Mouse and Keys start with an All apps profile, and you can add a profile for any app. Perch switches to it automatically when that app comes to the front.

Why does Perch need Accessibility and Input Monitoring?

Perch reads your mouse buttons and keys and sends new ones, which macOS only allows with these two permissions. Everything stays on your Mac, and the source code is on GitHub for anyone to check.

Does the clipboard history record passwords?

No. Perch skips passwords and anything apps mark as sensitive, and you can exclude any app from recording.

How many copies does the clipboard keep?

The popup keeps your last 50 copies and the menu bar shows 10. You can change both, pin favourites to the top, and clear the history on a schedule.

Why does macOS say it can’t verify the developer?

Perch isn’t notarized yet. The Terminal installer clears the macOS security warning for you. If you install with Homebrew or the DMG, open System Settings → Privacy & Security and click Open Anyway. You only need to do this once.

How do updates work?

Perch checks GitHub for a new version once a day, verifies the download’s checksum and opens it for you. Homebrew users can run brew upgrade --cask perch.

Can I move my settings to another Mac?

Yes. General → Backup exports everything to one file. Drop it on Perch on the other Mac and pick which sections to bring in.

How do I uninstall it?

Quit Perch and move it from Applications to the Trash. With Homebrew, run brew uninstall --cask --zap perch, which also removes its settings.
