Privacy

Perch collects no personal data. What you copy and type stays on your Mac. The only thing it sends is the daily update check to GitHub. There’s no account, no analytics and no tracking, in the app or on this website. Updated 11 November 2026.

The app

  • Clipboard history and snippets are stored only on your Mac, in Perch’s own settings and its Application Support folder. Passwords and copies that apps mark as sensitive are never recorded.
  • Accessibility and Input Monitoring let Perch read your mouse buttons and keys and send new ones. What you press is handled on your Mac and never leaves it.
  • Update checks: once a day, and when you click Check for updates, Perch asks GitHub for the latest release and downloads it if you choose to update. GitHub sees the request like any other web request. GitHub’s privacy policy covers that request.
  • Backup files are created only when you export one, and saved where you choose.

This website

  • No cookies, analytics or third-party scripts. Fonts are served from this site.
  • The page asks GitHub for the latest version number and download size, and the download links point to GitHub.
  • Our web host keeps standard server logs, such as IP address and time of request, for security and to keep the site running.

Questions

Perch is open source, so you can read exactly what it does on GitHub. For anything else, open an issue.
